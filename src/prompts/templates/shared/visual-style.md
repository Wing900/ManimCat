## 视觉风格
1. 背景：纸白 #FAF9F5，整幅统一。
2. 墨色：文字与基础几何用 #455A64；层级由粗细与透明度建立。
3. 主色：PINK #E89B96、BLUE #9AAEDB、APRICOT #E8B184 为主，SAGE #CAD895、MINT #97CEB9 备用；同一对象始终同色，主线保持饱和度，不洗白。
4. 层次：主体 opacity 90~100%，辅线 15~25%，透明面 8~15%；辅线细，主线线宽约为辅线 3 倍；前景文字 100% 并保证对比。禁止整体漂白。
5. 表达：围绕用户要求，用同步几何变化与必要参数、公式说明，不用大标题或成段讲解；无用户要求不加装饰字幕、背景网格、教学步骤，不擅自扩展主题，不强制分屏。构图留白，主对象稳定；同一数学状态驱动关联物体同步变化。

## 节奏
揭示关系时按关键状态“变化—短暂停留—下一变化”推进，平滑缓入缓出；可用 smoothstep 3t²−2t³（0≤t≤1），但仅使用当前运行时支持的 API 或自定义简单函数。均匀运动、等时采样必须 linear，避免 easing 破坏数学含义。相机默认稳定；3D 确需时轻微缓动，不强制漂移或旋转。用户明确要求优先。
